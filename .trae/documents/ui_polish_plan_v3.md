# UI 视觉微调与细节完善计划 (UI Visual Polish Plan)

## 现状点评
从截图来看，当前的悬浮窗已经具备了清晰的层级和现代感（毛玻璃背景、SF Symbols、粗体数字）。但作为追求极致体验的 macOS 应用，仍有几个细节可以打磨：

1.  **语言一致性 (Localization)**：国内金价下方的 `H:1148.02 L:1139.24` 使用了英文缩写，与整体的中文界面（“民生”、“国际金价”）略显违和。
2.  **色彩呼应 (Color Consistency)**：国内金价的图标使用了金黄色（`yensign.circle.fill`），而国际金价的地球图标（`globe`）目前可能是默认灰色。建议将其调整为**蓝色**，形成“金 vs 蓝（海洋/全球）”的视觉呼应。
3.  **数据时效性 (Timestamp)**：悬浮窗目前没有显示“更新时间”。用户无法判断当前价格是否为最新数据（特别是网络波动时）。
4.  **间距微调 (Spacing)**：国际金价列表的行高看起来略显紧凑，可以适当增加 2-4pt 的呼吸感。

## 优化方案

### 1. 汉化最高/最低价标签
-   **目标**：将 `H:` 和 `L:` 替换为中文单字，并优化排版。
-   **行动**：
    -   修改 `PriceCardView`。
    -   文本格式改为：`高: 1148.02  低: 1139.24`。
    -   或者使用更直观的箭头图标 `↑ 1148.02  ↓ 1139.24`（考虑到已经有涨跌箭头，用文字“高/低”可能更不易混淆）。**决定使用“高/低”**。

### 2. 国际金价图标着色
-   **目标**：增强视觉识别度。
-   **行动**：
    -   修改 `InternationalCardView`。
    -   将 `globe` 图标的颜色设置为 `.systemBlue` 或 `.systemIndigo`。

### 3. 增加更新时间脚标
-   **目标**：提供数据时效性反馈。
-   **行动**：
    -   在 `FloatingContentView` 底部增加一个极小的 Label。
    -   格式：`更新于 10:30:05`。
    -   样式：`.tertiaryLabelColor`，字号 9pt-10pt，右对齐或居中。

### 4. 布局微调
-   **目标**：提升阅读舒适度。
-   **行动**：
    -   微调 `InternationalCardView` 的 `rowSpacing`。
    -   确保“民生”标题与“国际金价”标题在左侧视觉上的垂直对齐。

## 预期效果
经过这轮微调，悬浮窗将不仅“好看”，而且“耐看”且“好用”，彻底消除“工程感”，达到成品级应用的精致度。
