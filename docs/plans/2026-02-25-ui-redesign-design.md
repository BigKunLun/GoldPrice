## PriceCard 组件

### 布局

```
┌─────────────────────────────────┐
│  民生     682.50     ↑ +0.82%  │  ← 主行
│         685.00 ▲  ▼ 680.20     │  ← 次行
└─────────────────────────────────┘
```

### 字体规范

| 元素 | 字体 | 大小 | 颜色 |
|------|------|------|------|
| 名称 | SF Pro | 11pt | `NSColor.secondaryLabelColor` |
| 价格 | SF Pro Mono (等宽数字) | 14pt | `NSColor.labelColor` |
| 涨跌 | SF Pro | 11pt | 涨 `systemRed` / 跌 `systemGreen` |
| 高低价 | SF Pro | 10pt | `NSColor.tertiaryLabelColor` |

### 卡片样式

- 背景：`NSColor.controlBackgroundColor` (10% opacity)
- 圆角：8pt
- 内边距：上下 6pt，左右 10pt
- 卡片间距：4pt

---

## 闪烁动画

**触发**：价格数值变化时

**效果**：
- 涨：背景短暂显示 `systemRed` (alpha 0.15)，0.5秒渐变消失
- 跌：背景短暂显示 `systemGreen` (alpha 0.15)，0.5秒渐变消失

---

## 毛玻璃背景

使用 `NSVisualEffectView`：
- `blendingMode = .behindWindow`
- `material = .hudWindow` 或 `.popover`
- `state = .active`

---

## 实现要点

1. 新建 `PriceCardView` 类继承 `NSView`
2. 使用 `NSVisualEffectView` 替换当前纯色背景
3. 使用系统原生颜色 API 自动适配深浅模式
4. 添加价格变化检测和闪烁动画
5. 调整窗口大小以适应新布局
