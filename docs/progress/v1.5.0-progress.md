## ❌ 发现的问题

### 1. 国际金价没有展示数据（核心 Bug）

**现象**: 伦敦金、纽约金价格显示为空

**调查结果**:
- 新浪财经 API (`hq.sinajs.cn`) 必须带 `Referer` 头才能访问
- 不带 Referer 返回 "Forbidden"
- 代码中已设置 Referer，但数据仍未显示

**待确认**:
- [ ] 网络请求是否成功
- [ ] 数据解析是否正确
- [ ] UI 更新是否正常

## 🔧 技术细节

### API 数据格式

**民生银行（京东金融）**:
```
https://api.jdjygold.com/gw/generic/hj/h5/m/latestPrice
返回: JSON
```

**国际金价（新浪财经）**:
```
https://hq.sinajs.cn/list=hf_XAU,hf_GC
返回: JS变量格式
格式: var hq_str_hf_XAU="价格,昨收,...,最高,最低,...";
```

字段解析:
- 字段0: 当前价
- 字段1: 昨收价
- 字段4: 最高价
- 字段5: 最低价
- 字段7: 昨收价(备用)
